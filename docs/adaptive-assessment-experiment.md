# Adaptive assessment experiment, procedure adaptive-beta-coverage-v1

This contract precedes the implementation. Default: disabled (`SIGNAL_ADAPTIVE_EXPERIMENT_ENABLED` must be exactly `true`). This procedure never writes qualification proofs or changes the accepted six-competency assessment. An experimental outcome is not an accredited grade.

Competence means successful application of the target module's saved Junior/Middle/Senior rubric, separately in each of its six competencies. The level is selected before the session; scores from different target levels are not pooled. Each observation is one independently generated, previously unexposed content family. Hidden tests and multiple parts of one answer are one observation.

One model: independent Beta(1,1) Bernoulli mastery per competency, probability of success on an eligible target-level family. Conditional independence and equal item difficulty within each competency are unvalidated assumptions. This is not CAT/IRT or SPRT. The thresholds below are experimental policy, not claims of predictive accuracy.

Require at least two rated, distinct families per competency before any conclusive outcome. Maximum24 answers,45 minutes. At full coverage, `level_supported` requires posterior P(p >= .7) >= .8 for every competency. `level_not_supported` requires posterior <= .2 for at least one competency after its minimum observations and full mandatory coverage. Otherwise continue, or return `insufficient_data` at resource/deadline/bank limits. Never turn a timeout, skip or infrastructure error into an incorrect response. Dates remain visible; there is no automatic age-based score decay.

First exclude unavailable releases, quarantined families, all prior personal exposures (including the accepted procedure), current-session/refinement families and families at the global1000-issue ceiling. First fill mandatory topic deficits. Thereafter maximize expected posterior variance reduction. Choose reproducibly among the top3 eligible items with a server-held seed and step. Persist issued family exposure. A refinement is another session linked to its parent and the same procedure/release/level; inherited observations and used families count once. Its total maximum remains24 and its original deadline is not extended.

Persist the original answer and its server receipt before optional scoring. A scoring failure leaves an unrated saved response for recovery; no next item is issued until it is resolved. CAS and command receipts prevent duplicate observations. Restart reconstructs state from immutable item snapshots plus saved answers; current generator changes do not affect replay. The next item is redacted from public output except for the currently issued prompt. Server seed and keys never leave the server.

Release gate: independent rubric review plus held-out real answers with external grades. Report false confirmations/nonconfirmations, insufficient outcomes, duration and per-specialization differences. Split by person and time; do not leak repeated families/attempts across sets. Simulation only tests mechanics, never demonstrates human validity. `scripts/evaluate-adaptive.ts` accepts externally labeled JSONL; no real corpus is bundled. Until those gates pass, keep the feature off.
