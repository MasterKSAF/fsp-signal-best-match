# Подбор и приглашения: фиксация исходников 9 октября 2026

Этот коммит сохраняет текущие изменения по отдельному запросу пользователя. Он не означает завершение независимой приёмки R01–R11.

## Что изменено

- В требованиях вакансии и приватного запроса можно отдельно разрешить заявленный навык или потребовать подтверждение. Минимальный уровень доступен только для навыков с отдельной проверкой. Для общего грейда также задан собственный режим. Старые требования без режима сохраняют значение «подтверждённый»; минимальный уровень не придумывается.
- Подбор, допуск в пул, покрытие навыков и сохранённые списки используют общие правила. Заявленное соответствие не получает баллы за подтверждение. Сохранение неподходящего резюме остаётся закладкой с отметкой о необходимости пересмотра.
- Кандидатские ответы API приглашений и контекстов проверок формируются по списку разрешённых полей. Внутреннее описание приватного запроса не передаётся кандидату; исторический снимок работодателя сохраняется. Версия основания обязательна для отправки приглашения.
- В кабинете показана компания работодателя, уточнены основание приглашения и публичная карточка компании. После отправки отклика кандидат переходит в «Мои отклики». Сохранена актуальная главная страница с осенним фоном.
- Обновлены OpenAPI, сгенерированные React/Zod-контракты, ORM и миграция `0017_recruiting_requirements.sql`.

## Обновление и границы проверки

Перед запуском нового API необходимы все миграции **0000–0017**. Сначала сделайте резервную копию своей базы, затем выполните обычный `pnpm db:migrate`. В этом проходе миграция на работающем стенде не применялась, процессы не перезапускались.

Проверки этого среза: **605/605 автоматических тестов**, TypeScript библиотек/API/веба/скриптов и сборки API/веба — PASS. Реальные HTTP/DB/UI-сценарии, сохранность истории после миграции, мобильный интерфейс, темы и независимая приёмка R01–R11 остаются незавершёнными. Также предстоит согласовать отображение заявленного грейда и пояснение `/employer/needs/:id/matching-status` с новыми режимами требований.

Материалы v2 в `delivery/2026-10-09` — презентация, видео и исходный ZIP — относятся к предыдущему срезу. Они не пересобирались и не являются доказательством нового функционала. Секреты, рабочие сессии, дампы и новые локальные QA-данные в этот коммит не включены.
