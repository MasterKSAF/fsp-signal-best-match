# Предпочтения движения 0.6.0

Скорость 0–5 с шагом 0,25 хранится на устройстве в `fsp-motion-speed`; прежний ключ `fsp-motion` system/reduced/off сохранён. Начальное значение 1×. Отдельный singleton store применяется перед React render, используется настройками и всем приложением, синхронизируется событиями storage между вкладками. Ошибка чтения/записи не ломает интерфейс: выбор работает в памяти текущей вкладки. Неизвестная скорость получает 1×.

Реальный коэффициент длительности `1/speed`: при 2× цикл бренда 90 s становится 45 s, при 0,5× — 180 s. Паузы масштабируются вместе с циклами. На 5× буквы не мерцают: это трансформации, без переключения высококонтрастных цветов. Для короткого появления блока минимальная длительность 120 ms, для функционального перехода 80 ms; длинные циклы масштабируются без такого ограничения.

0 и off выключают все декоративные циклы и переходы. Явный reduced и системный prefers-reduced-motion выключают их независимо от положительной скорости. Настройки показывают эффективное ограничение. Базовое содержимое видно и без animation; загрузка имеет текстовое состояние.

Серверные сроки экзамена, бизнес-квоты/cooldown, TTL, сети, автосохранение, debounce, время исследовательского протокола и измерения не используют этот коэффициент. Сообщение о достижении живёт реальные 6500 ms: CSS `milestone-time` также остаётся 6,5 s, а при выключенном движении полоса статическая. JSX/JS бизнес-таймеры сохранены.

Сезонный фон статический: 28 самостоятельно нарисованных контуров кленового, дубового и овального листа на широком экране, 14 на узком. SVG aria-hidden, focusable=false, без заливки и pointer events; остальные сезоны сохранены.
