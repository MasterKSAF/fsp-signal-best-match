# Signal 0.5.0 · комплект Best Match

Этот новый комплект подготовлен для локальной самостоятельной проверки. Запечатанные материалы 0.4.1 сохранены отдельно. Публикация, внешний хостинг и отправка заявки этим архивом не выполняются.

## Сначала проверить

1. Сверить SHA256 файлов с `submission-manifest.json`, затем прочитать `verification/final-report.json`. В нём фактические результаты текущей версии и ссылки на протоколы; непроведённые проверки не объявляются успешными.
2. Распаковать `fsp-signal-source-0.5.0.zip`. Внутри `fsp-signal/README.md`, `RELEASE-METADATA.json` и полный `SOURCE-MANIFEST.json`. Следовать инструкции сборки с Docker Compose и lockfile. Закрытый исходный ZIP после проверки не пересобирался ради добавления post-seal отчётов.
3. Для настоящего самостоятельного экзамена использовать `docs/reviewer-access.md` из исходников: каждому проверяющему отдельные кандидат и компания. Обзорная кнопка Demo показывает готовые синтетические примеры. Работающие пароли выдаёт локальный инструмент вне исходников; закрытых учётных данных и контактов тестовых кандидатов здесь нет. Контакты команды в презентации включены по её явному согласию.
4. Для воспроизведения принятого чистого запуска использовать `docs/source-release-0.5.0.md`, source seal, privacy proof и протокол clean launch из `verification/`. Нужны Python 3, PowerShell 7, Node.js 24, pnpm 11.25.0 и Docker Desktop. Из корня собственной распакованной `fsp-signal` создать `outputs/release-0.5.0` и скопировать туда **тот же неизменённый** `fsp-signal-source-0.5.0.zip` из внешнего комплекта. Затем заново выполнить `python scripts/audit-source-privacy-v050.py --expected-sha256 <SHA256 ZIP из submission-manifest.json>` и `scripts/clean-source-launch-v050.ps1 -ExpectedSha256 <тот же SHA256> -FreezeReleased` в PowerShell 7. Свежий аудит создаст собственный privacy proof в ожидаемом каталоге; перед запуском guard проверит его и ZIP. Протокол clean launch из комплекта показывает прежнюю выполненную проверку, его не подставляют вместо нового запуска. Отдельный стенд не изменяет рабочие базы.

## Что смотреть

- `Signal-Pitch.pptx` и `Signal-Pitch.pdf` — презентация команды и решения.
- `Signal-Technical-Description.pdf` — архитектура, методы, API, зависимости, оценка, сборка, запуск и миграции.
- `Signal-Demo.mp4` — монтаж настоящих экранов с вымышленными аккаунтами. Это демонстрация выполненных UI действий, а не непрерывная запись или исследование людей. `Signal-Demo-audit.json` связывает кадры, подписи и контрольные суммы.
- `verification/` — актуальные функциональные, браузерные, нагрузочные, приватностные и чистые проверки. Их типы и среды разделены. Windows working set не называется Docker memory.

## Основные сценарии

Кандидат создаёт до пяти резюме, отдельно выбирает специализацию и заявленный уровень, проходит опрос и квалификационный экзамен, сохраняет ответы и возвращается к своей попытке. Новые копии закрыты; копирование не создаёт новые достижения и не снимает ограничения повторов. Работа в двух вкладках защищена ревизиями.

Работодатель задаёт потребность и получает объяснимую выдачу по одному подходящему резюме человека. Каталог сочетает условия внутри одного резюме; сравнение сохраняет позиции полного пула. Приглашение и добровольный отклик открывают контакты лишь выбранной компании после согласия. Дополнительная практика компании не присваивает общий грейд Signal.

Жалобы, блокировки, ограничения и апелляции имеют проверяемые права и аудит. Жалоба сама по себе не является санкцией; её автор и исходный текст работодателю не выдаются. Апелляцию решает другой модератор. Обычные reviewer доступы не дают полномочий модератора.

## Границы результата

Данные демонстрации и нагрузочные фикстуры синтетические. Независимый человеческий пилот и промышленная интеграция ФСП ID не проведены. Дополнительная попытка исследована только offline; действующие интервалы повторов не менялись. Бонус ФСП между категориями разобран отдельно в `docs/fsp-category-policy-review.md`; формула автоматически не изменена. Локальные критерии нагрузки не являются SLA организатора или официальной оценкой конкурса.
