## Фактический текущий контракт

Сервис имеет **две стадии**: необязательный опрос рекомендует стартовый уровень; кандидат самостоятельно выбирает уровень объективной проверки, подтверждённая категория определяется обязательной матрицей. Затем работодатель формирует частный запрос, получает объяснимую подборку и приглашает конкретного кандидата с зарплатой. Задачи компании и публичные вакансии — отдельные дополнительные сценарии (B9; ASR 05:00–06:00).

Текущий банк — `signal-skills-2026-10-v6`, шесть модулей × Junior/Middle/Senior; матрица — `signal-category-competency-matrix-v2`. Backend требует заявленного Python **или** TypeScript, SQL и Backend engineering; Frontend — TypeScript, React и Frontend engineering. Проценты разных экзаменов не усредняются в общий грейд. Непройденный новый тест не переписывает прежние доказательства. До **пяти CV на аккаунт** — дополнительная возможность, не требование организатора (B6): паспорт принадлежит аккаунту, категория и применимость доказательств оцениваются для каждого целого CV, навыки разных CV не объединяются.

Matching `fsp-signal-match-v6` сначала проверяет допуск одного CV (роль/пул, согласия, видимость, специализация, категория, обязательные навыки и уровни), затем соответствие потребности и сравнимые подтверждения. Один человек занимает одно место. Каталог может показывать явно неподтверждённый профиль без выдуманного Junior. Зарплата обязательна, в рублях; gross/net отображаются и не конвертируются вымышленным курсом.

Контакты раскрываются адресно компании после принятия приглашения или самостоятельного отклика; согласия на подбор/каталог, публичность имени и grant контактов независимы. ФСП PUT сохраняет **только непроверенный ID**; отдельный импорт с согласием и сохранённым ID отвечает **503 `registry_not_configured`**. Ни ID, ни ошибка реестра не создают подтверждение, историю или бонус. Уже сохранённая обзорная Demo-история явно синтетическая. Сильнейший доверенный исход ФСП влияет только внутри подтверждённой категории, не заменяет тест и не присваивает спортивный разряд.
