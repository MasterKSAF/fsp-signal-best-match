# Поля и справочники Signal 0.6.0

Подпись остаётся над своим контролом; на ширине поля от 440 px короткие подписи выстраиваются в отдельную колонку. Длинные вопросы, описания, теги и мобильные формы остаются вертикальными. `FormField` связывает label/id, пояснение и ошибку через aria-describedby. Свободный текст не присваивает квалификацию.

| Поле | Контрол и варианты | Поиск | Свой текст | Сохранение |
|---|---|---|---|---|
| Должность/название резюме, роль в опыте/проекте, название потребности | Combobox, локальный список профессий | Да | Да | Исходное строковое поле; не меняет программу экзамена |
| Предметная область опроса/компании | Combobox, локальные бизнес-домены | Да | Да | Прежнее `industry`, без конвертации fintech/retail в IT-направление |
| Стек и заявленные/обязательные/желательные навыки | Теги и combobox, GET `/api/dictionaries/skills` | Да, в том числе управляемые aliases | Да | Известный вариант — canonical label; неизвестный — исходный текст, серверный `raw:` key |
| Личные навыки | Теги, локальный список | Да | Да | Массив softSkills; не превращается в подтверждённые навыки |
| Локация вакансии | Combobox, локальные города | Да | Да | Строковое поле локации |
| Формат профиля/потребности | Combobox, удалённо/гибрид/офис | Да | Да, в текущей строковой модели | Прежний workFormat; enum формата публичной вакансии остаётся закрытым |
| IT-направление, программа, грейд, видимость, статус, роли доступа, шкала опроса | Select/radio, разрешённые сервером значения | Нет | Нет | Прежние enum/проверки; нельзя добавить собственный грейд или роль |
| ФИО, контакты, компания, проект, описания, ссылки | Input/textarea соответствующего типа | Нет | Да | Прежние поля и ограничения, без искусственного словаря |

Поиск помогает найти вариант; частичное сходство не означает равенство. Java и JavaScript, SQL и PostgreSQL различаются. Выбор неизвестного обязательного навыка сохраняет условие; карта покрытия объясняет отсутствие проверки. Справочник навыков не выдаёт дополнительные баллы, согласия или сертификаты.

Combobox поддерживает Arrow, Enter, Escape, Tab, вставку и явный собственный вариант. Enter в раскрытом списке выбирает значение, не отправляя форму. Теги удаляются адресной кнопкой, несколько вставленных значений разделяются запятыми. При выходе из поля оставшийся текст добавляется, чтобы сохранение не потеряло ввод. Регистр/лишние пробелы и управляемые aliases не создают дублей; неизвестные смысловые различия сохраняются. Список не пополняется глобально произвольными пользовательскими значениями.

Источники городов/ролей/доменов — небольшой встроенный список подсказок команды, не внешний официальный классификатор. Каталог навыков — существующий версионируемый серверный список. Внешний платный поиск и передача личных данных не используются. Браузерные доказательства и окончательные границы приёмки публикуются в отчёте новой ревизии после проверок.
