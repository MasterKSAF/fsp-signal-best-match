# Лист подачи — Signal 0.6.0

Это локальный комплект команды Best Match. Готовность и точные SHA файлов фиксируются в `outputs/release-0.6.0/final-report.json`, `package-ready.json` и `submission-privacy-audit.json`. Публичного адреса здесь нет: он должен появиться после отдельного развёртывания. Материалы 0.5 не заменяют проверки 0.6.

## Что подготовлено к передаче

1. `Signal-Best-Match-0.6.0.zip` — общий комплект.
2. `fsp-signal-source-0.6.0.zip` — проверенные исходники, lockfile, миграции, инструкции и публичные протоколы. Проверка чистого запуска относится именно к SHA этого архива.
3. `Signal-Technical-Description.pdf` — архитектура, механика квалификации, категоризация, валидация, интеграция ФСП, API, версии библиотек, развёртывание: все восемь обязательных тем.
4. `Signal-Pitch.pptx` и `Signal-Pitch.pdf` — десять слайдов в официальном шаблоне, редактируемый исходник и PDF.
5. `Signal-Demo.mp4` и `Signal-Demo-audit.json` — монтаж настоящих локальных экранов с явным указанием синтетических данных. Это не непрерывная запись и не человеческий пилот.
6. `README-FIRST.md`, manifest и отчёты приёмки — инструкции запуска и границы каждого результата.

- После публикации проверить HTTPS, Origin/cookie, реальные адреса и отправку почты отдельной конфигурации. Локальный Mailpit не доказывает доставку через внешний SMTP.

## Как выдать индивидуальные доступы

Использовать документированный `scripts/provision-reviewers.ts` в отдельно подготовленном reviewer-окружении. Полный рецепт с точным origin/database и `--private-file` находится в `docs/reviewer-access.md`. Файл создаётся за пределами проекта и содержит случайные индивидуальные пароли. Он не входит в конкурсный архив. Каждому проверяющему передать только его кандидат/работодатель-пару отдельным согласованным способом. Общий Demo не использовать для независимой проверки квалификации.

## Что требует отдельного внешнего действия

Публичное развёртывание и URL; выдача доступов конкретным получателям; репетиция с человеком; загрузка файлов и подача в личном кабинете. Эти действия не выполнены автоматически. Настоящее подключение реестра ФСП требует предоставленного API и проверяемой связи личности. Категория Signal не является спортивным разрядом; победа в конкурсе не гарантируется.
