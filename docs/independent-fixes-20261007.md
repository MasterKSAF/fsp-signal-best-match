## Версии, источники и воспроизводимость

Новые квалификационные формы: `signal-backend-python-v7` / `signal-frontend-typescript-v3`,108 активных шаблонов. Завершённые v6/v2 и более ранние попытки используют сохранённую рубрику; числа не пересчитываются скрыто. SQL projection сохраняет `answerComparison`; structural rubric hash включает canonical_integer marker только там, где он действительно задан. Историческое JSON null не меняет прежний hash.

Новый контроль подбора впервые выполнен до последующей защиты вывода Invalid Date. Точные измеренные source snapshots и note сохранены. У frozen input даты валидны, поэтому ветка не меняет их значение; новый rank не выполнялся. Исправление ускоренного допуска для пустой потребности не является настройкой ранжирования.

Все старые FAILED runner receipts сохранены. Ошибка тестового клиента в пути `explanation.resumeId`, startup own-load harness и первоначальная неверная fixture catalog.items описаны рядом с новым фактическим прогоном; они не переименованы в PASS.
