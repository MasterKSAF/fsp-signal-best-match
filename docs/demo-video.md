# Демонстрационное видео Signal · 6 октября 2026

`outputs/submission/Signal-Demo.mp4` — 142 секунды,22 сцены,1440×900,H.264,25fps,без звуковой дорожки. Это подписанный монтаж настоящих UI-снимков, а не непрерывная запись действий. Источник — фактическая мобильная/настольная техническая приёмка на синтетических ordinary-аккаунтах; Demo отдельно обозначен.

Текущие версии: Backend `signal-backend-python-v6`, Frontend `signal-frontend-typescript-v2`, подбор `fsp-signal-match-v4`. Сырые JPEG проверены по SHA из `outputs/verification/mobile-refinement.json`, преобразованы в PNG без изменения декодированных RGB-пикселей. Receipt — `outputs/verification/video-refinement-conversion.json`. В MP4 разрешены только пропорциональное масштабирование, внешняя рамка и подписи; внутри UI ничего не исправлялось и не дорисовывалось.

## Происхождение кадров

- Ordinary путь: профиль, опрос, реальное решение шести Middle кейсов через UI, результат100, потребность, приглашение/принятие, отклик, рубрика практики, отключение регулярности и отзыв. Эти кадры сняты до финальной UI-пересборки. Runtime API input SHA совпадают с протестированной сборкой; весь ordinary путь после последней UI-правки заново не проходился.
- Формы23/24 и подбор25: промежуточная UI-сборка22ee с исправленным min-content overflow. Финальная правка отделяет показанный бонус ФСП; backend logic неизменна.
- Главная28/36, PDF27 и Demo30/31: финальный image `fd500f56`. Полный image ID и точный capture window записаны в конфигурации и видеоаудите.
- Binary identity прежнего и нового API bundle не измерена: прежний image недоступен; source input equality не выдаётся за binary equality.
- Регистрация/подтверждение email покрыты текущими HTTP-тестами. В этом capture window ordinary аккаунты были созданы локальным инструментом; видео не выдаёт их создание за наблюдение регистрации человеком.
- Кадры03 (найденный defect),21 (переход reflow) и22 (cooldown вместо формы) исключены. Скриншоты практики13/15 показывают видимую подписку/opt-out; невидимое поле ответа или крупный итог не дорисованы. Ответ/submit/10/10 зафиксированы в полном browser protocol.

## Проверка и пересборка

Окончательный `Signal-Demo-audit.json` содержит SHA MP4/конфигурации/генератора/каждого кадра, ffprobe metadata, полный decode и отдельную визуальную проверку середины каждой из22 сцен. Протокол `outputs/verification/demo-video-refinement.json` подтверждает actual video SHA и hash окончательного аудита. Успешное кодирование само по себе не означает визуальную приёмку.

Команда при наличии исходных PNG и ffmpeg/ffprobe: `python scripts/build-demo-video.py`. Проверка inventory/receipt без кодирования: `python scripts/build-demo-video.py --validate-only`. Все исходные файлы должны присутствовать; отсутствующий экран приводит к ошибке.

Фактически показанные аккаунты/компании/достижения — синтетика, без утверждения о людях или действующей интеграции ФСП. В итоговом комплекте поставляется MP4; raw screenshots остаются в локальных материалах проверки. Старый110-секундный MP4 и audit сохранены в `outputs/submission/history/2026-10-05`; они не подтверждают текущий банк или ранжирование.
