## Методика и B9

Skill proof принадлежит аккаунту: skillId, уровень, programVersion, исходная попытка, дата. Он применяется к подходящим резюме, не создаётся пять независимых копий проверки. SQL не подтверждает PostgreSQL, TypeScript не подтверждает React. Прежние экзамены не создают задним числом новых уровней навыков.

Обязательные компетенции категории не сокращаются удалением слабого навыка из стека. В каждой попытке шесть разных компетенций, нужно минимум5 успешных и все критические. Сильный React не повышает общую Frontend-категорию при недостаточном TypeScript/engineering. В реальном браузерном сценарии попытка28 подтвердила React Middle, общая Frontend-категория осталась Junior. Python Junior, SQL Middle и React подтверждены раздельно; неуспешный SQL Junior не удалил SQL Middle.

Общий verifiedScore не вычисляется из среднего модулей. Действующий сертификат категории содержит версию матрицы и ссылки на несколько свидетельств; не является выдуманным ID единственного экзамена. ФСП даёт приоритет только внутри допустимой подтверждённой категории и не заменяет обязательные навыки или грейд. Подтверждения Signal отделены от заданий работодателя.

B9 требует тестовую квалификацию по категории. Матрица нескольких обязательных проверок — собственная интерпретация исполнения этого требования, а не заявление, что ФСП отдельно одобрила именно модульную архитектуру. Историческая полноценная квалификация сохраняет свой scope; новые общие экзамены через старый endpoint при включённых модулях не выдаются.

## Ограничения

Junior/Middle — собственные уровни Signal. Не заявляются универсальная эквивалентность чужим системам, спортивный разряд, человеческая калибровка сложности или измеренная полезность для найма. Senior новой модели не подготовлен.

В банке —108 общих базовых семейств и36 дополнительных требований Middle из v2; их композиции не объявляются216 независимыми сюжетами. Middle требует обе части A+B, включая критические компетенции: одни ответы Junior не дают Middle. Семейства ротации учитываются между уровнями и версиями. Банк открыт; лимиты не дают абсолютной защиты от нескольких аккаунтов. Новая версия программы `signal-skills-2026-10-v3`, рубрика `six-competencies-critical-5of6-middle-outcomes-v3` без изменения. Снимки v1/v2, прежние ответы/решения/даты не переоценены; существующие свидетельства сохраняют свою версию, coverage обязательно для Middle v2 и v3. Экспериментальное уточнение не влияет на грейд и не наказывает кандидата.

Скачивание означает успешную выдачу файла сервером, не доказательство сохранения на диске. DOCX/PDF имеют один состав; шрифты могут дать разную пагинацию. Исторические просмотры не сгенерированы. Официальная внешняя ФСП-интеграция без подключённого источника не создаёт реальные достижения.

Сборка предупреждает о размере основного JS chunk (~740kB до gzip); PDF engine ~438kB загружается отдельно, worker ~1,26MB локальный. Это не ошибка сборки. Новая тяжёлая нагрузка, публикация и развёртывание вне изолированного стенда не проводились. Техническая приёмка «Решения ФСП» завершена ACCEPTED; это не обещание оценки жюри или человеческая калибровка экзаменов.
