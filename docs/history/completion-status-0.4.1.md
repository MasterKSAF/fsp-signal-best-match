## За пределом локальной поставки

- Предоставить доступные жюри ссылки и отправить комплект через личный кабинет.
- Провести живую репетицию питча; при желании — добровольный человеческий пилот и последующую визуальную полировку.
- Для публичного production настроить реальные SMTP/HTTPS и эксплуатацию; localhost не является внешней ссылкой.

Человеческий пилот и внешние API не выдаются за уже выполненную работу. ТЗ допускает командную эталонную разметку и воспроизводимый локальный запуск с видео.
