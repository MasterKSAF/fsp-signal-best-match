# Компактная главная, вход и консультант

**Историческая проверка интерфейса перед последним обновлением главной и закреплённой шапки.** Снимки и размеры ниже подтверждают прежний срез; актуальные тексты, фон и навигация проверяются отдельным итоговым протоколом. См. [completion-status.md](completion-status.md).

Обновление 5 октября 2026 года после повторной проверки стартового экрана. Заменяет описание главной в `ui-entry-2026-10-05.md`.

- Главная объясняет совпадение подтверждённых навыков, задач команды и условий работы. Две компактные карточки показывают ценность для кандидата и работодателя; больших кнопок входа в них нет.
- В правой части шапки одна кнопка «Вход». В модальном окне выбирается роль, затем обычный вход или Demo. В Demo автоматически показаны неизменяемые обозначения готового профиля и демонстрационный пароль; кнопка «Войти» создаёт сессию через отдельный разрешённый сервером demo endpoint. Эти значения не являются паролями обычных аккаунтов. Выключение Demo возвращает обычные поля; демонстрационный пароль в них не переносится.
- В подвале осталась ссылка «О сервисе». Убраны подпись команды и текст о раскрытии контактов. Правила доступа сохранены там, где пользователь принимает соответствующее решение.
- На фоне — лёгкие сезонные контуры; в октябре листья. Иллюстрация декоративная, статичная и не перекрывает управление.
- У каждой из шести букв Signal два разных коротких жеста, разнесённых во времени: растяжение, пружина, покачивание, уплотнение или наклон. Layout не меняется. Reduced/off и системное уменьшение движения отключают эффекты.
- Кнопка «Назад» в верхнем левом углу использует историю внутренних маршрутов с параметрами. При прямом открытии раздела есть безопасный возврат в обзор роли. Действия с данными она не отменяет.
- Меню темы закрывается после выбора, по клику снаружи, Escape и уходу фокуса. После Escape фокус возвращается к кнопке.
- Помощник справа снизу открывает диалог, отвечает на вопросы о продукте и предлагает три темы при неизвестном вопросе. В кабинете учитывает раздел и роль. Это локальная справка с подготовленной базой ответов, без внешней LLM или оператора. Переписка не сохраняется и не отправляется по сети. Модальные окна и текущая попытка проверки скрывают помощника.

## Проверка

Главная помещается без вертикального или горизонтального переполнения в проверенных viewport: 1280×720, 1024×600, 900×500, 760×550, 600×500, 390×640, 320×568. Проверена реальная высота документа; содержимое не скрыто через overflow:hidden. При чрезвычайно малой высоте или увеличении текста доступность важнее запрета прокрутки.

Проверены обе Demo-роли, возврат к обычным полям, открытие входа из помощника, неизвестный вопрос и три темы, светлая/тёмная/системная тема, закрытие меню выбором/снаружи/Escape, последовательный возврат методика → о сервисе → главная, анимации всех букв и отключение движения. На низком экране длинная форма входа прокручивается внутри окна. Ошибок JavaScript в финальной вкладке нет.

Полная production-сборка и TypeScript прошли. API не менялся; прежние 34 автоматических теста и 23 HTTP-группы относятся к предыдущему проверенному срезу и не выдаются за новый прогон. Приложение обновлено в Docker на порту 4310, данные БД сохранены.
