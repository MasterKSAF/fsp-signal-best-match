## Что показано

Кандидат создаёт резюме, проходит Python Middle, видит результат в паспорте, открывает поле ФСП ID, выгружает PDF и откликается на вакансию. Работодатель создаёт вакансию и приватный запрос, изучает отклик, добавляет и удаляет людей из отбора, сравнивает кандидатов и отправляет приглашение. Также показаны ответ на задание, темы оформления и помощник.

Профили и компания вымышлены. Ответы экзамена подготовлены заранее для демонстрации. Реестр ФСП пока не подключён: сохранение ФСП ID не подтверждает достижения. Один экзамен подтверждает отдельный навык; общий грейд требует всех обязательных навыков выбранного направления.

## Запуск и проверка

Команды запуска находятся в [README исходников](../../README.md), сведения о поставке — в [технической инструкции](../../docs/delivery-2026-10-09.md). При использовании ZIP сначала распакуйте папку `Signal/` и откройте её `README.md`.

582 автоматических теста и полная сборка относятся к базовой поставке. После исправления верхнего сохранения v2 выполнены проверка типов интерфейса и проверка в реальном браузере; полный набор повторно не запускался. Подробности — в [заметке v2](../../docs/source-v2-2026-10-09.md).

Рабочие `.env`, пароли, сессии и сырой конкурсный датасет в исходный архив не включены. Для запуска настройте собственное окружение по `.env.example`. Репозиторий приватный; жюри потребуется доступ. Промышленное развёртывание и человеческий пилот не заявлены. Прежний нагрузочный порог задержки не пройден; это ограничение сохранено в техническом описании.
